# OIBSIP Web Development Level 1

This OIBSIP workspace contains the Level 1 and Level 2 web development projects. Level 1 includes a responsive landing page, a personal portfolio starter, and a temperature converter. Level 2 includes a calculator, a tribute page, a persistent to-do app, and a front-end authentication demo.

- `WebDev-L1-LandingPage/` — Northstar product landing page (HTML/CSS)
- `WebDev-L1-PersonalPortfolio/` — Ikrar Ahmad portfolio starter (HTML/CSS)
- `WebDev-L1-TemperatureConverter/` — Celsius, Fahrenheit, and Kelvin converter (HTML/CSS/JavaScript)
- `WebDev-L2-Calculator/` — arithmetic calculator with operator precedence and keyboard support
- `WebDev-L2-TributePage/` — sourced tribute to Dr. A. P. J. Abdul Kalam
- `WebDev-L2-ToDoApp/` — task lists with edit, complete, delete, timestamps, and local storage
- `WebDev-L2-AuthDemo/` — registration, login, and protected dashboard learning demo

Before external submission, replace portfolio placeholders with accurate personal details and review each page on desktop and mobile. The authentication project is a learning demo, not production security. This folder is local work in progress; no posting or upload has been performed.
